## What this is

Skycharger daily-revenue dashboard, backed by the **Electric Era** and **Monta** APIs. Deployed as
Vercel project `skychargerrevenue` (`skyviewprojects` scope) → https://files-azure-eight.vercel.app.
Note the naming drift: local dir `files/`, repo `skychargerdailyrevenue`, Vercel `skychargerrevenue`.

- **Env vars** (Vercel, write-only — they cannot be read back): `EE_USERNAME`, `EE_PASSWORD`,
  `EE_ORG_ID`, `EE_CLIENT_ID`, `MONTA_CLIENT_ID`, `MONTA_CLIENT_SECRET`, plus the Blob trio.
- **Blob store:** `skycharger-revenue`.
- **Crons** (`vercel.json`): `/api/rebuild-baseline` weekly (Mon 09:00 UTC),
  `/api/log-accuracy` daily (09:00 UTC).
- **`baseline.json`** is committed and regenerated by the weekly cron.
- **[TODOS.md](TODOS.md)** holds deferred work from past reviews — read it before planning anything.

This project's **shrinkage projection model was the original**, later ported into the
`solar-dashboard` sibling project: `pace = soFar / expectedByNow`, blended against 1.0 by how much of
the day has elapsed, so early-morning noise doesn't swing the headline. If you need that math
explained, `solar-dashboard/ONBOARDING.md` documents it more thoroughly than anything here does.

## Skill routing

When the user's request matches an available skill, invoke it via the Skill tool. When in doubt, invoke the skill.

Key routing rules:
- Product ideas/brainstorming → invoke /office-hours
- Strategy/scope → invoke /plan-ceo-review
- Architecture → invoke /plan-eng-review
- Design system/plan review → invoke /design-consultation or /plan-design-review
- Full review pipeline → invoke /autoplan
- Bugs/errors → invoke /investigate
- QA/testing site behavior → invoke /qa or /qa-only
- Code review/diff check → invoke /review
- Visual polish → invoke /design-review
- Ship/deploy/PR → invoke /ship or /land-and-deploy
- Save progress → invoke /context-save
- Resume context → invoke /context-restore
- Author a backlog-ready spec/issue → invoke /spec
